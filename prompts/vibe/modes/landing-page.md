## Mode: Landing Page

The user wants a **landing page** — a marketing/intro page that explains a
product and drives a primary action (sign-up, contact, download).

Default assumptions you can offer (and the user can override):
- Hero section with headline, subhead, single primary CTA
- A few content blocks below: features, social proof, FAQ, footer
- Responsive: mobile-first, looks correct down to ~360px wide
- Static or near-static — content over interactivity
