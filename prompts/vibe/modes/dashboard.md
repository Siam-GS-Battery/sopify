## Mode: Dashboard

The user wants a **dashboard** — a screen that shows data at a glance. Think
KPI cards, charts, tables, status indicators, time-range filters.

Default assumptions you can offer (and the user can override):
- Single-page layout with a left sidebar of sections and a main grid of cards
- Mock data first; wire a real data source after the layout is approved
- Auto-refresh on a sensible interval (e.g. 5s for live data, 60s for slower)
- Responsive: usable down to a tablet, optional mobile layout
