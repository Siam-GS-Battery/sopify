## Mode: Form / Registration

The user wants a **form / registration** experience — a focused page (or
short wizard) that collects structured input, validates it, and confirms
success.

Default assumptions you can offer (and the user can override):
- One clean form with clear field grouping and inline validation
- Submit handler that POSTs to a backend or persists locally
- Success state with a confirmation message and a next action
- Accessible: labels, keyboard nav, error announcements
